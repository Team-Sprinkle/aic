# AIC Utility Tools

This directory contains standalone diagnostic tools that are useful during local
development.

## SpaceMouse Profiler

`profile_pyspacemouse.py` records local SpaceMouse input profiles using
`pyspacemouse`.

Common usage:

```bash
pixi run python aic_utils/tools/profile_pyspacemouse.py \
  --output-dir outputs/spacemouse_debug/local_profiler \
  --mode latency
```

Run both latency and separation profiles:

```bash
pixi run python aic_utils/tools/profile_pyspacemouse.py \
  --output-dir outputs/spacemouse_debug/local_profiler \
  --mode both
```

Useful options:

- `--mode {separation,latency,both}` chooses which profile type to record.
- `--stage-duration 6.0` controls seconds recorded per axis.
- `--signal-threshold 0.15` controls dominant-axis detection during alignment.
- `--axes x y z pitch roll yaw` controls which axes are profiled and in what
  order.

Generated files:

- `profile_<axis>.csv` for separation profile data.
- `latency_profile_<axis>.csv` for read-loop latency profile data.

## SpaceMouse Analyzer

`analyze_pyspacemouse.py` analyzes CSVs generated by the profiler.

Common usage:

```bash
pixi run python aic_utils/tools/analyze_pyspacemouse.py \
  --input-dir outputs/spacemouse_debug/local_profiler \
  --mode latency
```

Analyze both profile types:

```bash
pixi run python aic_utils/tools/analyze_pyspacemouse.py \
  --input-dir outputs/spacemouse_debug/local_profiler \
  --mode both
```

Useful options:

- `--mode {separation,latency,both}` chooses which analysis type to run.
- `--bleed-threshold 0.05` controls the cross-talk threshold used for separation
  analysis.

## Teleop Latency Analyzer

`analyze_teleop_latency.py` summarizes CSVs written by the LeRobot teleop
profiling hooks:

- `--teleop.profile_enabled=true`
- `--teleop.profile_csv=<path>`
- `--robot.action_profile_enabled=true`
- `--robot.action_profile_csv=<path>`

The older `AIC_SPACEMOUSE_PROFILE_CSV` and `AIC_LEROBOT_ACTION_PROFILE_CSV`
environment variables are still accepted as fallback paths when the matching
boolean profiling flag is enabled.

Common usage:

```bash
pixi run python aic_utils/tools/analyze_teleop_latency.py \
  "${PROFILE_DIR}/spacemouse_profile.csv"
```

```bash
pixi run python aic_utils/tools/analyze_teleop_latency.py \
  "${PROFILE_DIR}/action_profile.csv"
```

The summary reports timing percentiles, effective sample rate, nonzero command
ratio, command magnitudes, and per-axis signed/absolute integrals.

## SpaceMouse Recommended Settings:

- SpaceNav/SpaceMouse `Sensitivity = 2.00`
- SpaceNav/SpaceMouse `Swap Y-Z` enabled
- Run cartesian SpaceMouse teleop with
  `--robot.teleop_frame_id=gripper/tcp`.

Note that previously observed lagging isseus was not due to spacemouse latency. It was command clipping on
  `linear_z` and `angular_z`, plus poor behavior when using `base_link`.

```bash
pixi run lerobot-teleoperate \
  --robot.type=aic_controller --robot.id=aic \
  --teleop.type=aic_spacemouse --teleop.id=aic \
  --robot.teleop_target_mode=cartesian --robot.teleop_frame_id=gripper/tcp \
  --display_data=true
```

### Teleop Profiling Run

Profiling is disabled by default. Enable it explicitly with boolean flags:

```bash
PROFILE_DIR=outputs/spacemouse_debug/noop_lerobot/$(date +%Y%m%d_%H%M%S)
mkdir -p "${PROFILE_DIR}"

pixi run lerobot-teleoperate \
  --robot.type=aic_controller --robot.id=aic \
  --teleop.type=aic_spacemouse --teleop.id=aic \
  --robot.teleop_target_mode=cartesian --robot.teleop_frame_id=gripper/tcp \
  --teleop.profile_enabled=true \
  --teleop.profile_csv="${PROFILE_DIR}/spacemouse_profile.csv" \
  --robot.action_profile_enabled=true \
  --robot.action_profile_csv="${PROFILE_DIR}/action_profile.csv" \
  --display_data=true
```

Analyze both profiles:

```bash
pixi run python aic_utils/tools/analyze_teleop_latency.py \
  "${PROFILE_DIR}/spacemouse_profile.csv"
```

```bash
pixi run python aic_utils/tools/analyze_teleop_latency.py \
  "${PROFILE_DIR}/action_profile.csv"
```

### Detailed Experiement Conclusions

Category A, local input/publish:

- Local SpaceMouse read and LeRobot publish latency were healthy.
- `read`, `action`, and `send_action` p99 timings were all around 1 ms or less.

Category B, command semantics:

- The drift issue was caused by `linear_z` and `angular_z` command
  clipping/saturation, not latency.
- Lowering SpaceMouse sensitivity fixed the dominant clipping problem.
- After sensitivity adjustment, `linear_z abs_p95` dropped from `0.100000` to
  about `0.048571`, and `angular_z abs_p95` dropped from `0.100000` to about
  `0.019143`.

Category C, IK/nullspace:

- The IK issue observed with `base_link` was resolved by using `gripper/tcp`.
- No further IK-specific debugging is needed unless the issue reappears with a
  new posture, task, or SpaceMouse configuration.

Category D, teleop frame:

- `gripper/tcp` is the recommended SpaceMouse teleop frame.
- `base_link` is retained only as a comparison/debug frame.

### Follow-Up Checks

Use these only if the problem returns:

- Repeat a mixed teleop run and confirm `linear_z abs_p95 < 0.05` and
  `angular_z abs_p95 < 0.03`.
- Run orientation-only segments and verify that `linear_z` stays near zero.
- Run a 20-second neutral drift test and verify all axis integrals stay near
  zero.
- If saturation appears outside intentional full-range input, reduce per-axis
  scaling for `linear.z` and `angular.z` or increase deadband.

## Teleop ROS Response Profiler

`profile_teleop_ros_response.py` records ROS command timing, controller state,
TCP velocity/error, and selected joint posture values while teleop is running.

Common usage from a shell with the ROS environment sourced:

```bash
pixi run python aic_utils/tools/profile_teleop_ros_response.py \
  --duration-sec 30 \
  --out "${PROFILE_DIR}/ros_response.csv"
```

Useful options:

- `--command-topic /aic_controller/pose_commands`
- `--controller-state-topic /aic_controller/controller_state`
- `--joint-states-topic /joint_states`

Analyze the captured ROS response CSV:

```bash
pixi run python aic_utils/tools/analyze_teleop_ros_response.py \
  "${PROFILE_DIR}/ros_response.csv"
```

The analyzer reports command/state row counts, state age since last command,
actual TCP speed, command-to-state ratios, TCP error, and posture indicators
used for IK/nullspace debugging.
