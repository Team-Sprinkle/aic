# Route-consistent transport model retrain

I retrained the shared SFP-to-NIC / SC-to-SC diffusion transport actor on the corrected active dataset: **533 SFP and 83 Low Lateral Bypass SC training episodes**. The 22 SC CheatCode route prefixes that conflicted with the intended lateral bypass were excluded. I initialized from the earlier pre-mix diffusion checkpoint, ran all 6,000 planned updates on one GPU, and selected update 5,500 using grouped development data. The actor has 14.29 million trainable parameters plus an 11.18 million parameter frozen ImageNet vision encoder.

On the **same held-out observations** as the old checkpoint, first-action p95 translation error improved from **4.21 to 2.64 mm** on SFP public-anchor rows and **2.90 to 2.74 mm** on SC LLB rows. This confirms the new data fit improved imitation on recorded teacher states.

The matched autonomous Gazebo check still failed the transport gate: the old and new checkpoints each reached the required safe approach buffer on **0/3 SFP and 0/3 SC** starts. The new actor got within **10.97 mm** lateral distance on one SFP run, just outside the 10 mm buffer rule, but its gripper contacted a card. One SC run had p95 inference latency **354.7 ms**, above the 300 ms limit. None inserted. The rotated SC evaluation layout has no matching LLB teacher in this dataset, so its failure is a coverage stress test rather than evidence that LLB training itself is wrong.

The checkpoint is preserved for diagnosis and **not promoted** for handoff, insertion, or RL. No reserved final scene was opened. The next useful experiment is a bounded set of safe route-consistent corrections starting from states the actor actually visits, followed by the same autonomous gate; the rotated SC board first needs a verified LLB route. Repeating this same retrain is unlikely to resolve the observed route drift.
