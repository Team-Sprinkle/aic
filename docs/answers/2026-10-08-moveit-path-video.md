# MoveIt path video

[Watch the H.264 MP4 of the saved MoveIt path](</home/nas/chmin/aic_archives/2026-10-08_sfp_requested_corridor_v3_with_quat/case2_retreat_offline_h264.mp4>).

This example uses the five-card SFP development scene targeting card 3,
port 1. The dot follows the saved **retreat → align → approach** TCP route,
ending 85 mm before the opening. The left camera frame is static at the
actor takeover; the path plots move at 20 fps.

**This is an offline visualization of MoveIt's plan, not a Gazebo rollout.**
The planned arm path was never executed, so there is no real moving-camera
recording or observed cable motion for it. The [experiment record](../experiments/2026-10-08-sfp-requested-port-corridor-audit.md#video-of-a-saved-planned-path)
contains the rendering command and limits.
