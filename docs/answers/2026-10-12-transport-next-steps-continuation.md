# Transport continuation, October 12

I finished the current follow-up on the route-diffusion transport actor. It still has **no demonstrated safe, autonomous full insertion**: the earlier exact teacher-generator comparison was 0/6, and the two new bounded live pilots were 0/2. These are nonfinal development scenes; the reserved final scenes remain sealed.

The saved-input audit reconstructed the policy's commands to within 0.30 mm, so the current failure is unlikely to be a hidden camera preprocessing, frame-conversion, or diffusion-sampling mismatch. A controlled input swap showed a larger issue: on the second decision, replacing the actor's own previous command with the corresponding teacher command shrank action differences from **6–19 mm to 1–3 mm** across two SFP and two SC scenes. The model learned to use its previous teacher command as a route-progress cue; during deployment, an initially small command or delayed decision feeds back and the route drifts.

I tested two limited training repairs. Training without previous commands improved ordinary held-out action prediction, but not the decisive saved actor-state comparisons. Training with commands delayed by one or two decisions modestly reduced the early actor-state differences in all four scenes, yet none reached the predefined 50% reduction. Neither checkpoint was promoted or run autonomously.

Using **four diffusion sampling steps** lowered matched complete inference p95 to **241 ms SFP / 222 ms SC** on a shared GPU. One SFP scene reached the geometric approach buffer at **5.61 mm** lateral error, but the tool hit card 2. The five-card SC scene remained **247 mm** laterally away in the axial band. Neither inserted, so the faster setting is still a diagnostic, not a deployed choice.

I also found and corrected a test-provenance error: earlier runs named “JPEG-86” only set a value in the launcher manifest; Docker never received it. Their apparent improvement was repeatability variation, not evidence for that preprocessing change. Correctly forwarded codec pilots did not establish a reliable benefit.

**Next experiment:** before more model training, audit the existing actor-visited states for a *causally aligned* route-progress target or safe teacher continuation from the same observation. Prior actor-to-teacher takeovers cannot simply supply labels: some useful motion started only after the robot had already moved, and one officially successful continuation had a large cable/card point force. The bounded offline budget is the four frozen SFP/SC traces plus existing takeover records; collect nothing new unless a precise missing label and safety gate emerge. If a valid target exists, fit one matched actor comparison. Require at least **50% less early actor-state action error in all four scenes** and at most **1 mm** regression in ordinary held-out first-action p95 for each family. Only then test new grouped development starts for contact-free requested-port buffer arrival and complete p95 inference below 300 ms. If the label audit fails, change the route-progress/feedback design instead of collecting more routine demonstrations.
