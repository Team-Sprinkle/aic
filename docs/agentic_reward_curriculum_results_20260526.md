## Code changes validated

- Added `--insertion_action_guard_target_tip_servo_orientation_mode {inherit,quat,axis}` so the final target-tip servo can require full quaternion plug orientation while preserving existing axis-mode reward/eval paths by default.
- Added `--insertion_action_guard_target_tip_servo_override_final_orientation_when_gated` so the target-tip servo may override a zero-axial final-orientation hold only when its own lateral/orientation/module gates pass.
- Added `--insertion_action_guard_target_tip_servo_zero_rotation_when_gated`, `--insertion_action_guard_target_tip_servo_zero_rotation_theta_gate_rad`, and `--insertion_action_guard_target_tip_servo_depth_retention` as opt-in guarded variants. These were rejected by runs below.
- Added `--insertion_action_guard_target_tip_servo_gated_lateral_step_m` so lateral correction can stay aggressive before centering, then become smaller only after the target-tip axial gate opens. This preserves prior behavior by default.
- Added `--insertion_action_guard_target_tip_servo_deep_axial_step_m` and `--insertion_action_guard_target_tip_servo_deep_axial_activation_depth_m` so tiny near-entrance guarded insertion can switch to a larger bounded axial command only after a configured semantic tip depth. This preserves prior behavior by default.
- Added `--insertion_action_guard_target_tip_servo_plateau_pure_axial` and related plateau gates. This opt-in diagnostic replaces lateral correction with a bounded pure axial micro-step only when the deep target-tip servo is gated and measured depth progress has stalled. It is disabled by default and logs `insertion_action_guard_target_tip_servo_plateau_pure_axial_fraction`.

## Interpretation

The old axis-oriented warm-start is useful for approach and near-gate centering, but axis-only orientation was misleading: the stalled lip state can have axis theta near `0.01 rad` while full-quat error is about `0.32 rad`. Full-quat guide/servo gating fixes that false alignment and enables reproducible shallow insertion near `7 mm`. Continuing online SERL from the shallow `8 mm` checkpoint improved the corrected-depth metric to `12.118 mm`, so the old model is a useful warm start from the non-contact `10 mm` axial / `10 mm` lateral reset.
