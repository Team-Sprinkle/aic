## Adding a result

Before starting, copy [TEMPLATE.md](experiments/TEMPLATE.md) to
`docs/experiments/YYYY-MM-DD_short-name.md`. State the hypothesis, baseline,
changed variable, evaluation criteria, and stop rule. After the run, fill in
actual counts/outcomes and durable evidence paths, add one row here, and update
[STATUS.md](STATUS.md) only if the decision changes. Use explicit outcome labels
such as `success`, `partial`, `failed`, `no_score`, or `infrastructure_failure`.

Keep proposed work in the next-step list or an experiment's plan. A command
being generated, a synthetic audit passing, and a model finishing a scored trial
are separate outcomes.
