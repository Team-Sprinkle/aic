`docs/<report>.md` moved to `obsolete/docs/<report>.md`. Markdown links were
updated; historical commands and artifact locations retain their original
context. Archiving does not imply that every technical finding is invalid.

Active toolkit/setup/package guides remain in their original locations.

ledger. Add superseded narrative documents here when they no longer serve
as active instructions, and update incoming links in the same change.
